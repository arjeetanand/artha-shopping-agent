# Git commits

- Automatically commit each completed feature or bug fix without asking for confirmation.
- Run the relevant checks before committing. If checks fail, resolve failures caused by your changes; report unrelated failures and do not claim checks passed.
- Keep each commit focused on one feature or fix and use a descriptive commit message.
- Stage only files belonging to the completed work. Leave unrelated or in-progress changes untouched.
- Never commit secrets, `.env`, credentials, private user data, or generated build output.
- Do not push commits unless the user requests it.
